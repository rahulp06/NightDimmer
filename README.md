# NightDimmer

NightDimmer is an Android application that provides a screen dimming overlay to reduce eye strain during night-time usage and low-light environments.

## Features

- Adjustable screen dimming overlay
- Runs as a background service
- Lightweight and easy to use
- Helps reduce screen brightness below the system minimum
- Simple and clean user interface

## Built With

- Kotlin
- Android SDK
- Android Studio

## Installation

1. Clone the repository

```bash
git clone https://github.com/rahulp06/NightDimmer.git
```

2. Open the project in Android Studio

3. Sync Gradle and run the application on a device or emulator
